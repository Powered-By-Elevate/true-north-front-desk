    Kept in this browser only, never sent anywhere but github.com. Mint it at github.com/settings/personal-access-tokens, scope it to this one repository, give it Contents: read and write and nothing else. Revoking it costs one click and breaks nothing but this button.

    House rules this editor enforces

    A tile must open something. No URL means it renders as "Coming soon" rather than a dead link. If clicking it will never open anything, leave it off entirely.

    No personal links. Session, auth and tracking parameters are stripped on paste. They work exactly once, for whoever copied them. A tenant hostname is not personalization and is kept.

    The page cannot go blank. A broken or empty inventory loses to the copy baked into the page, so the worst case is stale, never empty.
